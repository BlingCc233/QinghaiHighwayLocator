# Gemini Logo Prompt

请为一款 Windows 10/11 x64 桌面软件设计一个现代、克制、专业的 SVG Logo。

软件名称：青海高速桩号定位
使用场景：青海省交通运输综合行政执法西宁高速支队韵家口大队，用于 G6 京藏高速和 S101 西宁至互助高速的桩号转 WGS-84 经纬度、路线定位和巡查辅助。

设计方向：

- 将“高速公路路线、定位 Ping、桩号刻度、青海高原”抽象成一个简洁符号。
- 视觉气质：可靠、清晰、工程化、现代，适合执法/巡查工作台，不要旅游宣传风。
- 图形应在 16 px、32 px、48 px、256 px 和 Windows 应用图标尺寸下都能识别。
- 采用几何化线条和少量实心形状，避免复杂插画、照片、地图截图、车流、建筑、人物和文字堆叠。
- 配色优先使用深墨蓝、青绿色和少量琥珀色；提供深色背景和浅色背景都清晰的版本。
- 不使用渐变、阴影、发光特效、噪点、3D、透视、立体 mockup 或外部字体。
- 不要把 G6 或 S101 的字母直接做成难以识别的变形字；若加入字母，只能作为极简辅助元素。

SVG 交付要求：

- 只输出一个完整、可直接保存为 `.svg` 的文件，包含 `viewBox`，建议 `viewBox="0 0 256 256"`。
- 使用纯 SVG path、circle、rect、line 等原生元素，不引用外部图片、CSS、字体、脚本或网络资源。
- 图形居中，四周保留安全留白；不要包含品牌名称、宣传语或版权水印。
- 颜色写成明确的 hex 值；控制在 3 至 5 种颜色以内。
- 确保 SVG 在浏览器、Windows 图标转换工具和 Wails 资源打包中可正常打开。
- 最后只返回 SVG 代码，不要返回 Markdown 解释或代码围栏。
